## Highlights

- Fixed workbook updating so replacing or changing an Excel file immediately saves and validates.
- Added Disconnect button in Excel Mapping to easily remove disconnected workbooks.
- Case-insensitive matching for Excel column headers.
- Support for Fancy Color diamonds without requiring standard Color field.
- Immediate workbook validation and caching upon saving configuration.
